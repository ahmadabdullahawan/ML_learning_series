# ML Learning Series

A hands-on series of ML models built from scratch to understand the math and intuition behind them — one topic at a time.

## Why this repo

Most of these models could be built in a couple lines with a library. The point here isn't the shortest path to a working model — it's understanding what's actually happening underneath: the math, the assumptions, and why things work (or break).

## Series

### 1. Linear Regression
- [ ] Simple linear regression
- [ ] Multiple linear regression
- [ ] Polynomial regression
- [ ] Regularized regression (Ridge / Lasso)
- [ ] Gradient descent from scratch

More series will be added as the learning continues.

## Structure

Each notebook/folder focuses on one concept, with explanations of the underlying math alongside the implementation.
